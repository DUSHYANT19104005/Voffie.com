# Voppify – Digital Marketing Agency Website

## 1.Project Overview

Voppify is a modern digital marketing agency website.

The website presents Voppify as a creative and technology-driven digital growth partner. It provides information about the agency, its services, work, process, insights and contact options.

The project is built using simple front-end technologies so that the code is easy to understand, maintain and update.

## 2.Technologies Used

- HTML5 – Used to create the structure of the website.
- CSS3 – Used for design, layout, colors and responsive styling.
- JavaScript – Used for the contact form interaction.
- No external libraries or frameworks are used.

## 3.Project Structure

Voppify/
- index.html – Home page
- about.html – About page
- services.html – Services page
- portfolio.html – Portfolio and Case Studies
- blog.html – Blog and Insights
- contact.html – Contact and enquiry form
- css/style.css – Main CSS file
- js/script.js – JavaScript file
- README.md – Project documentation

## 11.CSS

All styling is handled through:

CSS is used for:

- Layout
- Colors
- Typography
- Buttons
- Cards
- Spacing
- Navigation
- Forms
- Footer
- Responsive design

A common .container class keeps the content aligned across different pages.

The same CSS file is shared by all pages to maintain a consistent design.

## 12.JavaScript

JavaScript is stored in:

js/script.js

JavaScript is mainly used for the Contact form.

When the form is submitted:

1. The normal page refresh is stopped.
2. A success message is displayed.
3. The form is cleared.

The JavaScript is intentionally simple because this project does not require a backend.

## 13.Responsive Design

The website is designed to work on desktop and mobile screens.

A media query is used at:

max-width: 700px

On smaller screens:

- Navigation is hidden.
- Large headings become smaller.
- Cards change to a single-column layout.
- Buttons become easier to use.
- Footer and testimonial content stack vertically.

## 14.Basic SEO and Accessibility

The project includes basic SEO and accessibility practices.

- Each page has a meaningful title.
- The Home page includes a meta description.
- Proper heading tags are used.
- Form fields use suitable input types.
- Required fields use HTML validation.
- Buttons and links have clear text.
- Good contrast is maintained between text and background.

## 15.How to Run

1. Open the Voppify folder in VS Code.
2. Open index.html.
3. Run the project in a browser.
4. VS Code Live Server can also be used.
5. Use the navigation to test all pages.
6. Test the Contact form and mobile layout.

No external packages or installations are required.

## 16.Design Approach

The website uses a modern, minimal and professional design.

- Clear CTA buttons
- Consistent spacing
- Responsive layouts

The design avoids unnecessary animations and external libraries.
